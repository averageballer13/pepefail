ARCHITECTURE
------------
Frontend (racine du dossier) :
- index.html = landing (logo, wordmark, Enter Casino) ; casino.html = lobby ;
  games/*.html = 7 jeux jouables (plinko, mines, dice, crash, limbo, wheel,
  blackjack) ; token.html = page $FAIL ; pages/*.html = legal + rewards + recent.
- URLs propres : cleanUrls Vercel, aucun lien interne ne porte .html.
- assets/js/ : engine.js (Bank/Rank/XP démo), wallet.js (wallet Solana in-browser,
  clé chiffrée PBKDF2+AES-GCM dans localStorage, create/import/export/remove,
  auto sign-in après create/import), realmode.js (pont vers l'API : config, auth,
  balance mirror, paris, watcher de dépôts), wallet-panel.js (panel Deposit/
  Withdraw + modal Account), game-page.js (moteur UI des jeux, démo + réel),
  toast.js (popup top-middle), sfx.js (sons WebAudio), shell.js (topbar/sidebar/
  footer), token.js (page $FAIL).
- Icônes 100 % custom SVG (icons.js), pas d'emoji, pas d'effets "AI slop".
  Boutons : or = action principale, orange fluo = secondaire forte, glass =
  secondaire. Fond navy assorti au logo.

Backend (api/) — LIMITE VERCEL HOBBY : 12 fonctions max, donc UNE seule
fonction api/router.js + handlers dans api/_handlers/ (les dossiers _ ne
comptent pas) + rewrite vercel.json /api/:path* -> router.
- Auth : challenge/verify par signature ed25519 -> token HMAC 24 h.
- Provably fair : commit-reveal (hash de seed serveur publié, seed client,
  nonce atomique).
- Paris server-side : lamports entiers, BigInt, idempotence par refId, une
  seule manche ouverte par (adresse, jeu), infos cachées jamais renvoyées
  avant règlement. Champ de statut = "phase" (PAS "state", collision client).
- Dépôts : adresse dérivée PAR JOUEUR = HMAC-SHA512(secret maison,
  "deposit-v1:"+adresse) -> Keypair. Le client poll /api/wallet/sweep (4-8 s) ;
  le serveur balaie vers le VAULT et crédite le montant PLEIN (frais 5000
  lamports absorbés). Toast + son à l'arrivée.
- Retraits : débit d'abord (idempotent), transfert signé par le hot wallet,
  refund seulement si l'envoi n'a certainement pas été diffusé.
- DB : Upstash Redis REST (Lua EVAL atomique), fallback mémoire en dev.
  TOUTES les clés sont préfixées par réseau ("mainnet-beta:", "devnet:") —
  les soldes devnet ne peuvent JAMAIS devenir des dettes mainnet.
- House edge 1 % partout (RTP 99 %), source unique HOUSE_EDGE dans
  api/_lib/games.js, miroir exact du client. Blackjack S17 3:2.
