Provably Fair

Last updated: August 2026

"Trust us" is not a guarantee. Provably fair means you can check every result yourself, after the fact, without taking our word for anything.

Status: not live yet

The games on the site are interface builds. Verification is not switched on, so nothing here can be checked yet. This page describes the system we are implementing — when it is live, this box will say so and the verifier will be on this page.

1.The problem it solves

An online casino generates the random numbers that decide whether you win. If it wanted to, it could generate them after seeing your bet. You would never know. Licensing and audits are one answer to this. Cryptography is a better one, because it does not require anyone to be honest.

2.How it works

Three values decide every round:

  • Server seed — a random secret we generate. Before you bet, we show you its SHA-256 hash. The hash proves the seed already existed without revealing it.
  • Client seed — a value from your browser. You can change it at any time, so we cannot know it in advance.
  • Nonce — a counter that increases with every bet, so no two rounds are identical.

The result is derived by hashing these together. Because we published the server seed hash before you bet, we cannot change the seed afterwards without the hash no longer matching. And because you control the client seed, we cannot pick a server seed that produces a particular outcome for you.

3.Checking a result

  • Before betting — note the server seed hash shown in the game.
  • Set your own client seed — any string. Changing it is what makes the guarantee yours rather than ours.
  • Play. The nonce increases with each round.
  • Rotate the seed — when you ask for a new server seed, we reveal the old one in full.
  • Verify — hash the revealed seed and confirm it matches the hash you were shown. Then recompute the outcomes yourself with the seed, your client seed and the nonce.

If the hash does not match, we tampered with something and you have the proof. That is the entire point.

4.What it does not do

Provably fair proves a result was not manipulated. It does not remove the house edge, and it does not make you more likely to win.

  • Every game keeps its published edge. Verification does not change the odds.
  • A verified loss is still a loss. Fair is not the same as favourable.
  • It says nothing about whether we can pay out. That depends on the bankroll, which is why the token page covers it separately.

5.House edge by game

The edge is published on each game page, next to the RTP. We do not vary it per player, per session or per wallet. If that ever changes, it will be announced before it takes effect.
